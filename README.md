# Kdenlive: Minimal WhiteSur

Um layout simplificado para o Kdenlive focado em edições básicas, utilizando o esquema de cores **Apple WhiteSur**.

- **Interface Limpa:** Apenas Árvore do Projeto, Monitor e Linha do Tempo.
- **Tema WhiteSur:** Estética inspirada no macOS.
- **Foco:** Sem distrações, ideal para cortes e junções rápidas.

## 🚀 Instalação

1. **Tema:** Instale o [WhiteSur para KDE/Qt](https://github.com/vinceliuice/WhiteSur-kde) e selecione-o no Kdenlive em `Configurações > Esquema de Cores`.
2. **Layout:** Carregue o arquivo `.layout` deste repositório em `Exibir > Layouts > Carregar Layout`.
   - *Manualmente:* Feche os painéis extras (deixe Árvore do Projeto, Monitor e Linha do Tempo) e salve em `Exibir > Layouts > Salvar Layout`.

## 🛠️ Atalhos Essenciais
- `X`: Ferramenta de corte (Razor)
- `S`: Seleção (Ponteiro)
- **Efeitos:** Ative apenas quando necessário via `Exibir > Efeitos`.
